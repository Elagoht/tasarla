# Aşama 5 — Markdown: Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kart açıklaması ve yorumlar Markdown olarak gösterilir. goldmark (GFM, satır sonu korunur, ham HTML kapalı) render eder; çıktı dar izinli bir bluemonday politikasından geçer. Başlıklar bir seviye aşağı kaydırılır. Textarea'ların altında kısa bir sözdizimi yardımı bulunur.

**Architecture:** `internal/markup` paketi saf bir `Markdown(s string) template.HTML` sunar. `internal/web` bu fonksiyonu `markdown` adıyla şablon fonksiyonu yapar ve `richText`'in yerine koyar. Veritabanı, e-postalar, iCal, activity ve arama alıntıları ham metinle kalır.

**Tech Stack:** Go 1.26, `github.com/yuin/goldmark` v1.8.6, `github.com/microcosm-cc/bluemonday` v1.0.27 (ikisi de modül önbelleğinde).

**Spec:** `docs/superpowers/specs/2026-10-01-filtre-swimlane-ical-sablon-markdown-design.md` §7.

## Global Constraints

- `any` türü hiçbir yerde kullanılmaz.
- Kullanıcıya görünen her metin `locales/tr.json` ve `locales/en.json`'a birlikte eklenir.
- CSP değişmez: satır içi script ve `style` özniteliği yok. Render edilen Markdown da `style`, `class`, `id` ya da olay öznitelikleri taşımaz.
- goldmark ayarları:
  - GFM açık (tablo, üstü çizili, otomatik link, görev listesi);
  - `html.WithHardWraps()`;
  - ham HTML kapalı (`html.WithUnsafe()` kullanılmaz);
  - başlıklar bir seviye aşağı kaydırılır, `h6`'nın altına inmez.
- İzinli öğeler: `p br strong em del code pre blockquote ul ol li h2 h3 h4 h5 h6 table thead tbody tr th td hr a`, ayrıca yalnız `type="checkbox"` ve `disabled` taşıyan `input`.
  - `a[href]` yalnız `http`, `https` ve `mailto` şemalarını kabul eder.
  - Bağlantılara `rel` olarak `nofollow` ve `noreferrer` eklenir. `noreferrer`, HTML'de `noopener`'ı da içerir.
  - `ol[start]` sayıysa korunur.
  - `img`, `style`, `class` ve `id` izinli değildir.
- Anmalar (`@ad`) düz metin kalır.
- Commit mesajları semantik ve İngilizcedir; biçim konu satırı, boş satır, `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- Testler: `KANBAN_TEST_DATABASE_URL='postgres://kanban:kanban@localhost:55432/kanban?sslmode=disable' go test ./... -race -count=1`.

## Kararlar

- **`rel` değeri:** `nofollow noreferrer`'dır. bluemonday `noopener`'ı yalnız `target="_blank"` olan bağlantılara ekler. Bağlantılar aynı sekmede açıldığı için `noopener` gerekmez, `noreferrer` zaten onu da kapsar. Spec §7.1'deki üçlü yazımdan bu yüzden sapılıyor.
- **Tablonun kaydırılması:** tablolar CSS ile yatay kaydırılır (`.rich table { display: block; max-width: 100%; overflow-x: auto; }`). Sarmalayıcı bir `div` eklenmez, çünkü politika `div`'e izin vermez.
- **`richText`:** silinir. Testlerindeki bağlantı ve escape beklentileri `markup` testlerine taşınır.

## Review Focus

1. **XSS:** `<script>`, `<img onerror>`, `javascript:` ve `JaVaScRiPt:` bağlantıları, entity ile gizlenmiş şema (`&#106;avascript:`), `data:` URI, ham HTML bloğu, satır içi ham HTML, `[x](javascript:…)`, `<javascript:alert(1)>` otomatik linki. Hiçbiri çalıştırılabilir çıktı ya da izin dışı bir öznitelik üretmemeli. *(Task 1)*
2. **Satır sonu:** "a\nb" `<br>` ile korunmalı; iki satır sonu yeni paragraf açmalı. *(Task 1)*
3. **Yalnız düz metin içeren eski açıklamalar:** büyük ölçüde aynı görünmeli. URL'ler bağlantıya dönmeli, satırlar korunmalı. *(Task 1, Task 2)*
4. **Görev listesi:** `- [x] bitti` devre dışı ve işaretli bir checkbox olarak görünmeli. Panelde açıklamaya tıklayınca düzenleme açılır; checkbox'a tıklamak açıklamayı değiştirmemeli. *(Task 1, Task 2)*
5. **Başlık hiyerarşisi:** açıklamadaki `#`, sayfanın kendi `h1`/`h2`'sini bozmamalı. Kaydırma ve CSS boyutu bunu sağlamalı. *(Task 1, Task 2)*

package markup

import (
	"strings"
	"testing"

func TestMarkdownIsSafe(t *testing.T) {
	attacks := []string{
		"<script>alert(1)</script>",
		`<img src=x onerror=alert(1)>`,
		"[x](javascript:alert(1))",
		"[x](JaVaScRiPt:alert(1))",
		"[x](&#106;avascript:alert(1))",
		"[x](data:text/html;base64,PHNjcmlwdD4=)",
		"<javascript:alert(1)>",
		"<div onclick=\"alert(1)\">x</div>",
		"a <b onmouseover=alert(1)>b</b>",
		"![x](https://x.io/a.png)",
		"<style>body{display:none}</style>",
		"[x](https://x.io \"t\" onclick=alert(1))",
	}
	for _, in := range attacks {
		out := strings.ToLower(string(Markdown(in)))
		for _, bad := range []string{"<script", "javascript:", "onerror", "onclick", "onmouseover", "<img", "<style", "data:", "<div"} {
			if strings.Contains(out, bad) {
				t.Errorf("%q → %q contains %q", in, out, bad)
			}
		}
	}
}

```go
// Package markup renders user text written in Markdown as safe HTML.
package markup

import (
	"bytes"
	"html/template"
	"regexp"

	"github.com/microcosm-cc/bluemonday"
	"github.com/yuin/goldmark"
	"github.com/yuin/goldmark/ast"
	"github.com/yuin/goldmark/extension"
	"github.com/yuin/goldmark/parser"
	"github.com/yuin/goldmark/renderer/html"
	"github.com/yuin/goldmark/text"
	"github.com/yuin/goldmark/util"
)

// shiftHeadings moves every heading one level down, so a "#" in a card does
// not compete with the page's own titles.
type shiftHeadings struct{}

func (shiftHeadings) Transform(doc *ast.Document, _ text.Reader, _ parser.Context) {
	ast.Walk(doc, func(n ast.Node, entering bool) (ast.WalkStatus, error) {
		if h, ok := n.(*ast.Heading); ok && entering {
			h.Level = min(h.Level+1, 6)
		}
		return ast.WalkContinue, nil
	})
}

var md = goldmark.New(
	goldmark.WithExtensions(extension.GFM),
	goldmark.WithParserOptions(parser.WithASTTransformers(util.Prioritized(shiftHeadings{}, 100))),
	goldmark.WithRendererOptions(html.WithHardWraps()),
)

var policy = func() *bluemonday.Policy {
	p := bluemonday.NewPolicy()
	p.AllowElements("p", "br", "strong", "em", "del", "code", "pre", "blockquote", "ul", "ol", "li",
		"h2", "h3", "h4", "h5", "h6", "table", "thead", "tbody", "tr", "th", "td", "hr")
	p.AllowAttrs("href").OnElements("a")
	p.AllowURLSchemes("http", "https", "mailto")
	p.RequireParseableURLs(true)
	p.RequireNoFollowOnLinks(true)
	p.RequireNoReferrerOnLinks(true)
	p.AllowAttrs("start").Matching(regexp.MustCompile(`^[0-9]{1,6}$`)).OnElements("ol")
	p.AllowAttrs("type").Matching(regexp.MustCompile(`^checkbox$`)).OnElements("input")
	p.AllowAttrs("checked", "disabled").Matching(regexp.MustCompile(`^(|checked|disabled)$`)).OnElements("input")
	return p
}()

// Markdown renders s, GitHub-flavoured, line breaks kept and raw HTML left
// out, and keeps only the elements and links a card may show.
func Markdown(s string) template.HTML {
	var buf bytes.Buffer
	if err := md.Convert([]byte(s), &buf); err != nil {
		return template.HTML(template.HTMLEscapeString(s))
	}
	return template.HTML(policy.SanitizeBytes(buf.Bytes()))
}
```

  - bluemonday `<a>` öğesine `href` olmadan izin vermez; `AllowAttrs("href").OnElements("a")` öğeyi de izinli kılar. `<input>` için `AllowAttrs(...).OnElements("input")` yeterli olmayabilir: bluemonday bazı öğeleri hiçbir zaman kabul etmez (`input` bu listede olabilir). Çıktıda checkbox yoksa:
    - bluemonday'in `input`'u kabul edip etmediğini kendi kaynağından kontrol et (`~/go/pkg/mod/github.com/microcosm-cc/bluemonday@v1.0.27`).
    - Kabul etmiyorsa goldmark'ın görev listesi render'ını değiştir: checkbox yerine `☑ ` ya da `☐ ` metnini yazan bir `NodeRenderer` (`extension.TaskCheckBox` düğümü için).
    - Bu durumda testteki beklentiyi buna göre yaz ve rapora ekle.
  - Autolink'te `www.x.io` biçimini GFM `http://` ile tamamlar; testte yalnız `https://` kullanıldı.
